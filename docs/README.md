# Halloween Party Bot — стартовый комплект

Статус: реализованы bootstrap, домен, очередь, регистрация и путь фотоответа до баллов (этапы 1–3), 2026-10-19.
Код: `../PartyBot.Api`, тесты: `../PartyBot.Tests`. Команды запуска — в [корневом README](../README.md).

## Как использовать

1. Из корня репозитория выполнить `dotnet restore PartyBot.slnx` и `dotnet tool restore`.
2. Проверить `dotnet build PartyBot.slnx` и `dotnet test PartyBot.slnx`.
3. Запустить bootstrap: `dotnet run --project PartyBot.Api --launch-profile Bootstrap`.
4. Продолжить этапы из `TASKS.md`, сверяя поведение с `ACCEPTANCE.md`.

Если обнаружено противоречие, не выбирать правило молча: показать конкретный пример и предложить минимальное исправление. Новая явная инструкция владельца проекта имеет приоритет; соответствующие документы обновить вместе с кодом.

## Границы MVP

Одна вечеринка, один запущенный экземпляр бота, до 70 участников. Регистрация, персональные задания, фотоответы, ручная проверка, рейтинг, дисквалификация, архив, аудит. Без LLM, отдельного веб-интерфейса, платежей и собственного файлового хранилища.

## Что заполнить перед реальной игрой

- Каталог заданий: стабильный ID, текст, положительная целая награда (default 1), повторяемость.
- N1 — задержка после пропуска; N2 — после подтверждённой отправки ответа.
- Telegram ID суперадмина и организаторов, ID рабочего чата, архива и журнала.
- Часовой пояс отображения Europe/Moscow; время в БД — UTC.
- Секретный токен, постоянный путь БД, резервное копирование.

N1/N2 не согласованы. Для разработки допустимы явно помеченные значения 1 и 1 минута; production-запуск игры требует явно заданных значений. Нельзя выдавать разработческие значения за решение владельца.
